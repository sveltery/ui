# Native example scaffolds

`Example` and `ExampleWrapper` are native Svelte ports of [the actual pinned shadcn scaffold](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/bases/base/components/example.tsx) at immutable commit `d75a96ab781f3d659be1ad287347d5887ce9f2fc`. The complete source has only the `cn` dependency; no Base primitive, icon, Next component or layout controller is required. [The byte-exact fixture](../tests/reference/example-scaffold.tsx), [SHA-256 manifest](../tests/reference/example-sources.json) and pinned [MIT notice](../tests/reference/LICENSE) establish source provenance. Tests are source-derived local comparisons; no copied upstream runtime test inventory is claimed.

Import both helpers, `ExampleProps` and `ExampleWrapperProps` from `@sveltery/ui/example` or the package root. Their [single native implementation](../apps/docs/registry/bases/base/ui/example/index.ts) also supports source copying beside `ui/shared/classes.js`. Locating the upstream `components/example` helper under the local distributable `ui/example` directory and exporting named Svelte props types are additional distribution APIs, recorded in [the compatibility register](upstream-differences.md). The package remains private and unpublished.

`ExampleWrapper` retains two divs. Its fixed outer shell is `w-full bg-muted dark:bg-background`; all consumer attributes, events, styles, ref, children and merged classes target the inner `data-slot="example-wrapper"` grid. The grid retains `min-h-screen`, centered max widths, minimum width zero, responsive padding/gaps and two columns from `md`. A caller's `data-slot` overrides the inner default. The caller cannot target the outer shell through a new prop.

`Example` retains an outer `data-slot="example"` div with the source flex/container classes, optional title div and `data-slot="example-content"` div. `title` is consumed, escaped and rendered only when truthy; it is not a native title attribute or heading. `containerClassName` merges into the outer div; `class` merges into the content div. All other native props, styles, events and the bindable ref target the outer div, preserving caller `data-slot` precedence. Content retains the source flex/gap/padding/card/color classes, Lyra/Sera rounding selectors and direct div child selector: only a direct div whose class does not contain `w-` gets width 100%. Missing snippets render empty content without a synthesized child.

React `className`/children/object styles/refs/synthetic events become Svelte `class`/snippets/CSS strings/bindable native div refs or attachments/native events. Initially undefined or null refs adopt the correct host and clear to null on removal. Native host identity survives reactive changes; attachment replacement cleans up old attachments and installs new ones without replacing hosts. These framework substitutions earn no React API parity credit. The helpers add no role, heading semantics, keyboard handling, new render API or variant prop.

[The three required custom variants](../tests/reference/example-variants.css) are copied unchanged from [the pinned globals stylesheet](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/app/globals.css): class-based dark selection and descendant Lyra/Sera selection. They are registered in the docs and documented fresh-consumer stylesheet. No other upstream global CSS, token map, typography, dark palette or full style preset is ported by this slice. Geometry/styles compare the pinned React scaffold and Svelte under the same declared consumer theme. Explicit CSS-variable witnesses prove source dark selection independently of palette selection; these checks do not establish upstream theme/preset parity.
