# Experimental native Card

Seven native `div` parts follow the exact [shadcn Card wrapper](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/bases/base/ui/card.tsx) at `d75a96ab781f3d659be1ad287347d5887ce9f2fc`: Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent and CardFooter. This slice adds no Base primitive. The private unpublished package and broader readiness remain blocked.

Import the parts and corresponding named props types from `@sveltery/ui/card` or the package root. Card accepts `size="default"` (the default) or `size="sm"`. The exact [Nova Card section](../tests/reference/card-nova.css), upstream lines 243–266, sets spacing to 16px or 12px with the standard 4px spacing token, reduces small titles, applies borders/backgrounds to footers and supports header borders, descendant footers and first/last images. The caller can override `data-slot` and `data-size` through the native prop spread, just as upstream; changing them may change the CSS selectors that match. Consumer classes use the unchanged shared class helper and retain pinned merge precedence.

All parts forward native div attributes, CSS-string styles, native event handlers and symbol attachments. They accept snippet children and `bind:ref` with omitted, initially undefined or null state; refs receive the actual div and clear to null on removal. CardTitle stays a div, adding no heading role. No part adds focusability, keyboard handling, state controller, form control, semantic landmark or automatic accessible name. Consumers supply any appropriate native semantics. Existing Button/remote-field/native-reset contracts are unchanged.

The [example gallery](../apps/docs/examples/base/CardExample.svelte) ports seven complete actual example bodies: Default Size, Small Size, Content Edge to Edge, Header with Border, Footer with Border, Header with Border (Small) and Footer with Border (Small). The [paired React gallery](../tests/reference/CardGallery.tsx) executes the actual pinned wrapper and [byte-exact selected functions](../tests/reference/card-selected-examples.tsx). Supplemental action/grid and class/prop override probes are labeled separately. No dedicated upstream Card tests were identified; assertions are source-derived local comparisons, not copied upstream tests.
