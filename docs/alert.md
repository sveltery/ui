# Proposed native Alert

This bounded native Svelte port follows [shadcn-ui/ui Alert at `d75a96ab781f3d659be1ad287347d5887ce9f2fc`](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/bases/base/ui/alert.tsx). Alert-local source starts at landed Label main `b7d5ed09ebc6530adc57be1d85cfa8a4680ea3c2`. Shared exports, Nova inclusion, canonical compatibility/readiness/installation records and consumer wiring are held until pending [SkeletonCard PR19](https://github.com/sveltery/ui/pull/19) and [AspectRatio PR20](https://github.com/sveltery/ui/pull/20) serialize. The exact proposed [shared integration patch](alert-shared-integration.patch) targets that baseline and needs explicit reconciliation against their eventual integrated main. It has not been applied to this branch's shared files. The patch uses zero context to satisfy repository whitespace checks. Check the baseline with `git apply --check --index --unidiff-zero docs/alert-shared-integration.patch`; after serialized integration, reconcile through three-way application/review rather than accepting line offsets blindly. The implementation is proposed in [draft PR21](https://github.com/sveltery/ui/pull/21). No merge eligibility is claimed for this preparatory draft.

Four wrappers are implemented: `Alert`, `AlertTitle`, `AlertDescription`, `AlertAction`. Each renders a single native `div`. Root retains `cn-alert group/alert relative w-full` and the private CVA default/destructive variants. An absent or undefined variant selects default; null selects neither variant class. No render/size/dismissal API or Base primitive is added. `alertVariants` is private upstream and remains private locally. Proposed package imports are `@sveltery/ui/alert` and the root after serialized integration; named native props types are Svelte conveniences beyond the pinned four runtime exports.

Root defaults to `role="alert"`; caller props retain upstream override/omission precedence for role and all four data-slots. Title/Description retain their exact descendant-anchor underline/offset/hover classes. Consumer classes merge after pinned tokens with the existing `clsx`/`tailwind-merge` helper; CVA is already pinned at 0.7.1. The port does not invent keyboard listeners, focus management, automatic dismissal or live-region content mutation behavior.

React `className`, children, object CSS, refs and synthetic events become Svelte `class`, snippets, CSS strings, bindable refs or symbol attachments and native events. Refs can begin undefined/null, receive the actual native div, and clear to null when removed; attachment replacement and removal invoke cleanup. Classes can use Svelte native class arrays/objects through the existing class helper. These framework-specific assertions do not earn React parity credit. Existing framework-substitution acceptance covers the established spellings and native integration where exposed; no new Alert-specific acceptance or separate named-type acceptance is inferred from tests.

The [Nova source subset](../tests/reference/alert-nova.css) is pinned lines 19–42. This packaging change is a scaffold adaptation, not proof of full upstream stylesheet parity. Root lays out icon-free Basic as a grid. Actual source selectors react to descendant `data-slot=alert-action`, direct SVG children and named `group/alert`, including action positioning, icon size, title column, destructive description color and paragraph spacing. Supplemental native SVG/action/link probes exercise these rules without claiming the deferred icon/Badge gallery functions. Both paired harnesses share current consumer theme tokens; complete upstream dark palettes remain unported.

Only **Basic** is selected from the [complete pinned examples](../tests/reference/alert-example.tsx). Its three Alert compositions preserve exact text, classes and title/description combinations. Example/ExampleWrapper become native sections/headings in the [Svelte example](../apps/docs/examples/base/AlertExample.svelte) and [React gallery](../tests/reference/AlertGallery.tsx). The actual selected React function is retained byte for byte. Full scaffold layout and APIs remain unimplemented; separate scaffold acceptance is not recorded.
