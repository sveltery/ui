# Configurable example icons

`IconPlaceholder` is an app-only gallery helper, outside the published UI package. It replaces the former fixed X reference with genuine selected-icon rendering. The immutable [placeholder](../tests/reference/icons/upstream/icon-placeholder.tsx), [loader](../tests/reference/icons/upstream/create-icon-loader.tsx), five generated export maps and configuration sources come from shadcn-ui/ui commit `d75a96ab781f3d659be1ad287347d5887ce9f2fc`. Its actual path includes `(app)/(create)`; the old gallery import alias lacks `(app)` and is resolved only in the fixture. [Source provenance](../tests/reference/icon-sources.json) preserves exact bytes, upstream lock excerpts and package integrity pins.

The complete pinned generated maps contain 186 Lucide, 181 Tabler, 191 Hugeicons, 157 Phosphor and 156 Remix icons: 871 genuine exports. All exports exist in the exact package versions: lucide-react 0.474.0, @tabler/icons-react 3.34.1, @hugeicons/core-free-icons 1.2.1, @hugeicons/react 1.1.1, @phosphor-icons/react 2.1.10 and @remixicon/react 4.7.0. These are development dependencies used for extraction/reference execution. React remains the repository's previously pinned version; the upstream lock used React 19.2.3, so this comparison does not claim an exact upstream React runtime environment.

[The generator](../scripts/generate-icons.mjs) extracts SVG geometry without React in the Svelte client. [The inventory](../tests/reference/icon-data.json) hashes the generator and every data output. Frozen package integrity, source hashes and byte-exact regeneration gate acceptance. Lucide ISC, Tabler/Phosphor MIT and Remix Apache notices are retained in [reference licenses](../tests/reference/icons/licenses/lucide-LICENSE). The Hugeicons 1.2.1 core package declares MIT but omits its advertised bundled license; immutable official monorepo [MIT notice](../tests/reference/icons/licenses/hugeicons-core-LICENSE.md) and [free-pack licensing evidence](../tests/reference/icons/licenses/hugeicons-core-license-evidence.txt) are preserved separately. The restricted [Hugeicons React 1.1.1 license](../tests/reference/icons/licenses/hugeicons-react-1.1.1-LICENSE.md) remains attached to its original development reference dependency; its renderer source is not copied into the native renderer. Only free core geometry is extracted.

`IconLibraryProvider` supplies a reactive resolved library value through Svelte context, defaulting to the pinned `lucide`. `IconPlaceholder` selects the name from that library's prop. A missing/empty selected name renders nothing immediately. Each previously unseen library/name loads asynchronously and shows the genuine Lucide Square fallback. Names cache independently, unknown exports resolve to nothing, and changing names/libraries cannot display a stale completion. Caller library-name attributes are preserved on SVG as upstream emits them; no automatic accessibility label or hidden attribute is invented.

The genuine loader consumes caller `strokeWidth` for settled icons: ordinary libraries retain their defaults, Hugeicons always receives 2. The unsuspended Square fallback receives the caller width. Library-specific SVG defaults, color, Tabler's `stroke` consumption/title child, class merging, child order and native caller spread precedence are preserved. An explicit empty class is preserved during SSR and client updates through native DOM synchronization, because Svelte otherwise removes it on the client. Native Svelte class/CSS strings/events/snippets/bindable SVG refs and symbol attachments replace React spellings and lifecycle APIs. Package-only extras such as Phosphor weight/context, Hugeicons Pro variants and library-specific size props are outside the upstream `React.ComponentProps<svg>` placeholder contract and are not exposed by this Svelte helper.

The Next/nuqs URL, preset encoding/decoding, history synchronization, icon picker and full design-system configuration are not ported. The Svelte and React diagnostic providers substitute only the resolved `iconLibrary` value; library reactivity and glyph behavior remain executable. React.lazy/Suspense/module preloading become Svelte await blocks and cached native data imports. Internal scheduling, Suspense boundary markup and module topology are framework substitutions, not byte-equivalent runtime APIs. Empty/other galleries remain separate compositions until actual functions land with their dependencies; adding this helper alone gives them no gallery parity credit.

Validation is source-derived: [DOM](../tests/dom/icons.test.ts) and [SSR](../scripts/check-icons-ssr.mjs) execute all 871 genuine exported glyphs, additional caller/default/nullable prop cases, Square fallback, reactive names/configuration, SVG namespaces, refs, native events, children and attachment cleanup. [Secured browser probes](../tests/browser/icons.spec.ts) compare every library with the genuine pinned placeholder, delay actual data/export modules to witness Square, preserve null behavior and reject stale display. No dedicated icon runtime tests exist in the audited immutable shadcn tree, so none of these assertions are described as copied upstream tests. This app-only helper does not add package-consumer API surface; existing fresh archive/source-copy consumer gates remain required.

Full local verification, secured hosted browser CI with zero retries, independent review and configured automatic review must cover the final head before parent approval and developer merge. A passing generator or historical run establishes no broader component/gallery/production readiness. The proposed PR and final-head evidence will be recorded here after creation; a specific user acceptance of configuration/framework substitutions is not recorded.
