# Configurable icons

`IconPlaceholder` and `IconLibraryProvider` now have one canonical implementation in [the UI registry](../apps/docs/registry/bases/base/ui/icons/index.ts), exported from the package root and `@sveltery/ui/icons`. The original app-only implementation landed in [PR #29](https://github.com/sveltery/ui/pull/29) as main `125da200ec560c96560489abea6221054fdf58ac`; [public distribution PR #33](https://github.com/sveltery/ui/pull/33) subsequently landed as main `8d92c62d9f2006aff60d1c947e0921d8f3dc6c32`, moving that implementation and redirecting the docs gallery without a second renderer. It replaces the former fixed X reference with genuine selected-icon rendering. The immutable [placeholder](../tests/reference/icons/upstream/icon-placeholder.tsx), [loader](../tests/reference/icons/upstream/create-icon-loader.tsx), five generated export maps and configuration sources come from shadcn-ui/ui commit `d75a96ab781f3d659be1ad287347d5887ce9f2fc`. Its actual path includes `(app)/(create)`; the old gallery import alias lacks `(app)` and is resolved only in the fixture. [Source provenance](../tests/reference/icon-sources.json) preserves exact bytes, upstream lock excerpts and package integrity pins.

The complete pinned generated maps contain 186 Lucide, 181 Tabler, 191 Hugeicons, 157 Phosphor and 156 Remix icons: 871 genuine exports. All exports exist in the exact package versions: lucide-react 0.474.0, @tabler/icons-react 3.34.1, @hugeicons/core-free-icons 1.2.1, @hugeicons/react 1.1.1, @phosphor-icons/react 2.1.10 and @remixicon/react 4.7.0. These are development dependencies used for extraction/reference execution. React remains the repository's previously pinned version; the upstream lock used React 19.2.3, so this comparison does not claim an exact upstream React runtime environment.

[The generator](../scripts/generate-icons.mjs) extracts SVG geometry without React in the Svelte client. Generated ESM assets live under the canonical registry `icons/generated` directory so secured Vite development serving and Node/browser module loading use supported native modules. Each module retains the applicable original license notice. [The inventory](../tests/reference/icon-data.json) hashes the generator and every data output. Frozen package integrity, source hashes and byte-exact regeneration gate acceptance. Lucide ISC, Tabler/Phosphor MIT and Remix Apache notices are retained in [reference licenses](../tests/reference/icons/licenses/lucide-LICENSE). The Hugeicons 1.2.1 core package declares MIT but omits its advertised bundled license; immutable official monorepo [MIT notice](../tests/reference/icons/licenses/hugeicons-core-LICENSE.md) and [free-pack licensing evidence](../tests/reference/icons/licenses/hugeicons-core-license-evidence.txt) are preserved separately. The restricted [Hugeicons React 1.1.1 license](../tests/reference/icons/licenses/hugeicons-react-1.1.1-LICENSE.md) remains attached to its original development reference dependency; its renderer source is not copied into the native renderer. Only free core geometry is extracted.

`IconLibraryProvider` supplies a reactive resolved library value through Svelte context, defaulting to the pinned `lucide`. `IconPlaceholder` selects the name from that library's prop. A missing/empty selected name renders nothing immediately. Each previously unseen library/name loads asynchronously and shows the genuine Lucide Square fallback. Names cache independently, unknown exports resolve to nothing, and changing names/libraries cannot display a stale completion. Caller library-name attributes are preserved on SVG as upstream emits them; no automatic accessibility label or hidden attribute is invented.

The genuine loader consumes caller `strokeWidth` for settled icons: ordinary libraries retain their defaults, Hugeicons always receives 2. The unsuspended Square fallback receives the caller width. Library-specific SVG defaults, color, Tabler's `stroke` consumption/title child, class merging, child order and native caller spread precedence are preserved. An explicit empty class is preserved during SSR and client updates through native DOM synchronization, because Svelte otherwise removes it on the client. Native Svelte class/CSS strings/events/snippets/bindable SVG refs and symbol attachments replace React spellings and lifecycle APIs. Package-only extras such as Phosphor weight/context, Hugeicons Pro variants and library-specific size props are outside the upstream `React.ComponentProps<svg>` placeholder contract and are not exposed by this Svelte helper.

The Next/nuqs URL, preset encoding/decoding, history synchronization, icon picker and full design-system configuration are not ported. The Svelte and React diagnostic providers substitute only the resolved `iconLibrary` value; library reactivity and glyph behavior remain executable. React.lazy/Suspense/module preloading become Svelte await blocks and cached native data imports. Internal scheduling, Suspense boundary markup and module topology are framework substitutions, not byte-equivalent runtime APIs. Empty/other galleries remain separate compositions until actual functions land with their dependencies; adding this helper alone gives them no gallery parity credit.

Validation is source-derived: [DOM](../tests/dom/icons.test.ts) and [SSR](../scripts/check-icons-ssr.mjs) execute all 871 genuine exported glyphs, additional caller/default/nullable prop cases, Square fallback, reactive names/configuration, SVG namespaces, refs, native events, children and attachment cleanup. [Secured browser probes](../tests/browser/icons.spec.ts) compare every library with the genuine pinned placeholder, delay actual data/export modules to witness Square, preserve null behavior and reject stale display. No dedicated icon runtime tests exist in the audited immutable shadcn tree, so none of these assertions are described as copied upstream tests. The [fresh archive/source-copy probes](../tests/installation/icons.spec.ts) additionally exercise the public API, actual asynchronous ESM chunks, SSR/hydration, all five libraries, null/stale results and native lifecycle cleanup. [Public type assertions](../tests/icons-types.ts) and the isolated package consumer check declarations, root/subpath identity, byte-identical geometry and full license presence. A Vitest-only exact public-barrel alias unifies the diagnostic app import with canonical source DOM/cache helpers; it changes no expectation and provides no packed-module serving evidence. The actual docs/browser app and archive consumers import the packed API, while source-copy consumers execute the full copied closure under their native src/lib directory. No app/browser aliases, fs allowlist changes or sandbox relaxations are used.

## Public API and source-copy closure

Import `IconPlaceholder`, `IconLibraryProvider` and the readonly `iconLibraries` list from `@sveltery/ui/icons` or the root of the reviewed local archive. The same barrels export `IconLibraryName`, `IconPlaceholderProps` and `IconLibraryProviderProps`. The provider's `library` prop is reactive and defaults to `lucide`. All five icon-name props remain required strings, as in the pinned placeholder; set a selected string to empty to render nothing. Native SVG attributes, `class`, CSS strings, native events, child snippets, `bind:ref` and symbol attachments retain the tested contract. Internal loaders, caches, SVG helpers and generated data are not public exports.

```svelte
<script lang="ts">
  import { IconPlaceholder, IconLibraryProvider, type IconLibraryName } from '@sveltery/ui/icons';
  let library = $state<IconLibraryName>('lucide');
</script>
<IconLibraryProvider {library}>
  <IconPlaceholder lucide="ArrowLeftIcon" tabler="IconArrowLeft" hugeicons="ArrowLeft01Icon" phosphor="ArrowLeftIcon" remixicon="RiArrowLeftLine" aria-label="Previous" role="img" />
</IconLibraryProvider>
```

For source copies, use the same pinned checkout and consumer setup from [installation](installation.md), then copy the entire directory:

```sh
cp -R ../sveltery-ui/apps/docs/registry/bases/base/ui/icons src/lib/components/ui/
```

Import the public names from `$lib/components/ui/icons`. Keep every sibling implementation file, the six `generated` ESM assets, all five `licenses` files and the repository/package notices. This directory contains the full icon source/data closure; it depends on Svelte 5.57.1 and `clsx` 2.1.1, and needs no Base primitive, React renderer, icon package, Nova style rule or external asset server at runtime. Future registry wrappers import the sibling `../icons/index.js`; their source copies must include this same directory. Archive builds ship the closure under `dist/icons`, including license headers and byte-exact full notices. No fs allowlist or browser sandbox changes are required.

Public packaging and the named native props types are local distribution/API adaptations: pinned React places this helper in its app, rather than exporting this Svelte library surface. The PM approved implementing this bounded distribution on 2026-10-02; no specific user acceptance of the provider/framework substitutions is recorded. The package-wide MIT license does not replace the ISC, MIT or Apache-2.0 licenses of the generated assets. Restricted Hugeicons React renderer source and its development-reference license are excluded from the public closure. Existing unimplemented URL/preset configuration, picker, complete gallery compositions and broader readiness limits remain unchanged.
