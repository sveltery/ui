# Kbd and KbdGroup

The bounded native Kbd and KbdGroup wrappers follow [shadcn-ui/ui `d75a96ab781f3d659be1ad287347d5887ce9f2fc`](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/bases/base/ui/kbd.tsx) and [Nova lines 779–786](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/styles/style-nova.css#L779). Both render native `kbd` elements. KbdGroup preserves the actual upstream host even though React annotates its props as a `div`. These leaves introduce no Base primitive or keyboard shortcut handler.

Import `Kbd`, `KbdGroup`, `KbdProps` and `KbdGroupProps` from `@sveltery/ui/kbd`. Both expose native attributes, a children snippet, `class`, CSS-string `style`, native event handlers, symbol attachments and `bind:ref`. Refs accept omitted, undefined or null initial values, receive the actual `HTMLElement` and clear to null on removal. Consumer `data-slot` overrides the default; merged consumer classes retain the pinned precedence. Kbd retains `pointer-events-none` and `select-none`; KbdGroup does not add those classes. Neither adds a role, tab stop, event suppression or custom-render API.

The [examples](../apps/docs/examples/base/KbdExample.svelte) now propose seven selected [actual upstream example bodies](https://github.com/shadcn-ui/ui/blob/d75a96ab781f3d659be1ad287347d5887ce9f2fc/apps/v4/registry/bases/base/examples/kbd-example.tsx): Basic (`Ctrl`, `⌘K`, `Ctrl + B`), Modifier Keys (`⌘`, `C`), KbdGroup (`Ctrl`, `Shift`, `P`), Arrow Keys (`↑`, `↓`, `←`, `→`), With Icons (three genuine glyphs), With Icons and Text (`Left`, `Voice Enabled`), and With samp (`File`). The two icon bodies await final-head gates; InputGroup and Tooltip remain omitted. A separate class-override probe exercises merging and Nova overrides.
