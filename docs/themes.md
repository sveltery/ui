# Modern theme and style inventory

The immutable reference is shadcn-ui/ui `d75a96ab781f3d659be1ad287347d5887ce9f2fc`. The [source inventory and hashes](../tests/reference/themes/sources.json) retain byte-exact modern registry theme, base-color, style, configuration and merge sources plus all eight original stylesheets. These sources use the existing [MIT notice](../packages/ui/THIRD_PARTY_NOTICES.md). Legacy HSL themes in upstream public assets are a separate historical inventory and are not substitutes for the modern OKLCH themes.

Canonical styles are Vega, Nova, Maia, Lyra, Mira, Luma, Sera and Rhea. Modern theme records contain seven complete bases (Neutral, Stone, Zinc, Mauve, Olive, Mist and Taupe) and seventeen accent overlays (Amber, Blue, Cyan, Emerald, Fuchsia, Green, Indigo, Lime, Orange, Pink, Purple, Red, Rose, Sky, Teal, Violet and Yellow). Both modes are required. An accent record is incomplete by itself: upstream merges a complete base first, then the selected theme record.

The proposed implementation preserves the existing unscoped Nova default and adds opt-in scoped style assets for implemented components. It adds exact source-derived light/dark tokens and documented base-plus-accent selection, public package and source-copy assets, paired responsive computed-style browser probes and fresh isolated consumers. Missing components, legacy themes, the complete example gallery, cross-browser behavior, live assistive technologies and production readiness remain unimplemented or blocked. Source hashing and local assertions do not establish complete upstream parity. Exact-final-head local and secured hosted gates, independent review, configured automatic reviews and PM approval remain required before merge.
