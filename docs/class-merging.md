# Pinned class merging

The modern shadcn source at immutable commit `d75a96ab781f3d659be1ad287347d5887ce9f2fc` imports the standalone [`cn` package](https://github.com/shadcn-ui/cn/tree/788fe9bf71006c84e387c14b8d356f60f74956b6). Its original lock resolves `cn` 0.2.2. This repository uses that exact published package directly; it has its own engine and generated tables and no runtime dependencies. It does not rewrite the engine or silently select current `cn` releases.

[The shared helper](../apps/docs/registry/bases/base/ui/shared/classes.js) delegates class merging to `cn`. The existing Svelte state-class callback wrapper remains: Base-backed hosts evaluate the callback with their current state, and its returned value passes through the same pinned engine. This is the existing framework adaptation, not a new React callback API. Public icon attribute joining independently retains its genuine `clsx` 2.1.1 dependency, and component variants retain `class-variance-authority` 0.7.1.

The previous handwritten `tailwind-merge(clsx(...))` helper differed on public class strings containing nonbreaking space (`U+00A0`) or line separator (`U+2028`): it reduced `p-2` plus `p-4` to `p-4`, whereas pinned `cn` preserves the original string. The correction preserves that exact pinned behavior. ASCII spaces and tabs still merge conflicting classes. React source fixtures now resolve the actual package rather than a common replacement alias; their source bytes remain unchanged.

[The immutable manifest](../tests/reference/cn-sources.json), [original MIT reference](../tests/reference/cn-upstream/LICENSE) and [package notices](../packages/ui/THIRD_PARTY_NOTICES.md) retain source and artifact identities. Five byte-exact original `cn` conformance programs run against the installed package with original `clsx` 2.1.1 and `tailwind-merge` 3.6.0 oracle versions and the upstream CI setting of 300,000 fuzz cases. A temporary harness supplies their original relative package layout; both bare imports and relative engine/CLI paths resolve to the same installed package. This validates a reusable dependency and adds zero upstream UI ordinary runtime-test credit. Independently authored [public DOM regressions](../tests/dom/cn-class-input.test.ts), paired SSR, package and secured browser/consumer probes are supplemental integration evidence. Benchmark, size, generated-artifact freshness and Node 20/22 matrix acceptance remain unclaimed.

Archive consumers receive the exact runtime dependency through the package manifest. Source copies containing `shared/classes.js` must install `cn@0.2.2` and retain the full notices; use the [matching installation scaffold](installation.md). The packed library retains the complete dependency MIT notice. This change does not advance the Base pin, complete missing wrappers or replace native browser and assistive-technology gates.
