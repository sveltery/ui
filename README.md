# Sveltery UI

Svelte 5 components that port [shadcn/ui](https://ui.shadcn.com) onto [Sveltery Base](https://github.com/sveltery/base), the Svelte port of Base UI. Experimental and unreleased. Independent and unofficial; not affiliated with MUI, Base UI or shadcn.

Components: Alert, AspectRatio, Avatar, Button, Card, Dialog, Empty, Kbd, Label, Separator, Skeleton, Table and Textarea.

```sh
pnpm install
pnpm verify
pnpm --filter @sveltery/docs dev
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the layout and checks. Original code is [MIT](LICENSE); derived code keeps its [upstream notices](packages/ui/THIRD_PARTY_NOTICES.md).
