# Sveltery UI

Svelte 5 components that port [shadcn/ui](https://ui.shadcn.com) onto [Sveltery Base](https://base.sveltery.dev), the Svelte port of Base UI. Experimental and unreleased. Independent and unofficial; not affiliated with MUI, Base UI or shadcn.

Components: Alert, AspectRatio, Avatar, Button, Card, Dialog, Empty, Kbd, Label, Separator, Skeleton, Table and Textarea.

```sh
pnpm install
pnpm verify
pnpm --filter @sveltery/docs dev
```

The docs are at [ui.sveltery.dev](https://ui.sveltery.dev). See [installation](https://ui.sveltery.dev/docs/installation) to add it to an app with the CLI and [CONTRIBUTING.md](CONTRIBUTING.md) for the layout and checks.
